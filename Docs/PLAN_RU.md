# План работ «Тени Парижа» (UE 4.27, ПК 2014 года)

Работа идёт автоматически: запланированный запуск каждые 6 часов выполняет **один** следующий незакрытый этап, проверяет его, коммитит и пушит.
Каждый этап рассчитан так, чтобы занимать заметно меньше одного 5-часового окна лимита подписки. Так у владельца остаётся запас не меньше 5 % для своих дел. Если лимит кончился посреди этапа, следующий запуск продолжает с отметки в журнале.

## Порядок одного запуска (обязателен)
1. Прочитать `CLAUDE.md` и этот файл. Взять первый этап со статусом `[ ]` или `[~]` (начатый; продолжить с записи в журнале).
2. Пометить его `[~]`, закоммитить и запушить сразу, чтобы параллельный запуск не взял тот же этап.
3. Работать экономно:
   - не больше двух подагентов на этап;
   - большие файлы читать частями;
   - логи сокращать (head/grep);
   - веб-поиск — не больше 5 запросов.
4. Проверять на каждом шаге и быть строгим критиком себя и агентов:
   - стенд `Tools/StubCheck/check.sh` (после этапа 1) — все затронутые `.cpp` и unity-сборка, плюс линтер;
   - чистые тесты математики (поз, геометрии, звука);
   - графику и позы — рендером в PNG через `legacy/lutece` без окна, с личным просмотром каждой картинки;
   - найденные ошибки исправлять в этом же запуске.
5. Закрыть этап `[x]` и дописать в «Журнал» 2–4 строки: что сделано, результаты проверок, что осталось сомнительным. Закоммитить (по-русски) и запушить в `main`.
6. Если этап не влез, оставить `[~]` и записать в журнал точное место остановки.

## Этапы
1. [~] **Стенд проверки.** Каталог `Tools/StubCheck`:
   - макет заголовков UE 4.27 с точными сигнатурами (без UE5-методов) и автогенерацией `*.generated.h` (typedef `Super`);
   - `check.sh` (clang/g++ `-fsyntax-only`, режим unity-сборки);
   - линтер (UObject-указатель без UPROPERTY, затенение членов, UE5-имена, порядок include);
   - README.
2. [ ] **Порт каркаса на 4.27.**
   - `.uproject`: 4.27, без Enhanced Input и Modeling;
   - `Target.cs`: V2; `Build.cs`: + AnimGraphRuntime, AnimationCore, MeshDescription, StaticMeshDescription;
   - `DefaultEngine.ini`: DX11, без Lumen/Nanite/RT/VSM/DF;
   - `DefaultScalability.ini` (Low/Medium/High/Epic);
   - `DefaultInput.ini` и `TPCharacter` на BindAxis/BindAction;
   - `TPGameMode`;
   - `TPEnvironment` облегчить: без объёмных облаков и тумана, SkyLight пересъёмка раз в игровой час, только 6–8 ближайших фонарей включены и без теней.
3. [ ] **Порт паркура и боя:** `TPTraversal*`, `TPCombat*`, `TPGuard*` через стенд до чистоты.
4. [ ] **Порт жителей, сюжета и интерфейса:** `TPHUD`, `TPCitizen*`, `TPIdentity*`, `TPStory*`, `TPSave*` через стенд до чистоты.
5. [ ] **Анимация, часть 1.** `TPAnimPoseMath.h`: двухзвенный IK с pole-вектором, позы целями конечностей, переходы (порт `legacy/lutece/anim/lu_humanoid.c`).
   - Тест в `Tools/AnimTest`: нет NaN, длины костей сохраняются, колени и локти сгибаются в нужную сторону, нет скачков между кадрами.
   - PNG-листы поз на скелете манекена.
6. [ ] **Анимация, часть 2.** `UTPAnimInstance` и свой `FAnimInstanceProxy` (Evaluate):
   - локомоция из анимаций манекена UE4 со смешиванием по скорости;
   - процедурная походка как запасной вариант;
   - `TPAnimSetup` (оптимизация NPC: OnlyTickPoseWhenRendered, редкое обновление дальних).
7. [ ] **Анимация, часть 3.** Позы паркура и боя:
   - паркур: вис с руками на кромке через GetHandIK, лазание, подтягивание, перемах, бег по стене, кувырок, приземление;
   - бой: удары, блок, контратака, уклонение;
   - IK стоп, наклон в поворотах, взгляд;
   - OverrideSequences для Mixamo;
   - PNG-проверка.
8. [ ] **Архитектура, часть 1.** Порт `TPCity*` и `TPTexGen*` на 4.27.
   - Библиотека элементов: профили карнизов, тяги, наличники, арки, пилястры, руст, переплёты, ставни.
   - Превью фасадов в PNG.
9. [ ] **Архитектура, часть 2.**
   - Модули в UStaticMesh и HISM с отсечением мелочи на 60–80 м, мелочь без теней.
   - Мансардные крыши, слуховые окна, трубы, балконы с решётками.
   - Подсчёт треугольников и вызовов отрисовки (≤ 1.5 млн / ≤ 1500).
   - Превью.
10. [ ] **Архитектура, часть 3.**
    - Улицы: брусчатка, вывески, навесы, фонари, деревья, фонтан, телеги, бочки.
    - Текстуры 512² с выветриванием и подтёками.
    - `tp_setup.py` под Python API 4.27.
    - Превью улиц с уровня глаз и с крыши.
11. [ ] **Внешность, часть 1.** Одежда 1789 года на скелете манекена (`TPAppearance*`, `TPOutfit*`): кафтан, камзол, треуголка, рубаха, кюлоты, платья, чепцы, мундир стражи. Бюджет ≤ 15 тыс. треугольников, превью.
12. [ ] **Внешность, часть 2.** Лица, волосы, парики, цветовые вариации толпы, LOD ≤ 3 тыс.; ApplyHero/ApplyGuard/ApplyCitizen; превью.
13. [ ] **Звук.** Процедурные эффекты на `USoundWaveProcedural` (`TPAudio*`): шаги по камню, черепице и дереву, удары, звон шпаг, ветер на крышах, гул толпы, колокола.
14. [ ] **Музыка.** `TPMusic*`, порт `legacy/teni_v1/game2/audio.c`: спокойная барочная днём, напряжённая в погоне и бою, ночная; плавные переходы.
15. [ ] **Интеграция.** Подключить анимацию, внешность и звук к герою, страже и жителям; полная проверка стендом всех файлов и unity-сборки.
16. [ ] **Независимая рецензия.** Отдельный агент, не писавший код, проверяет API 4.27, бюджеты производительности и логические ошибки. Исправить найденное.
17. [ ] **Документация.** `Docs/SETUP_RU.md` под UE 4.27 (Launcher, VS 2019/2022 Community, Third Person, `tp_setup.py`, управление, что присылать при ошибке) и итоговый отчёт.
18. [ ] **Резерв:** доработки по ошибкам сборки, которые пришлёт владелец, и по замечаниям рецензии.
