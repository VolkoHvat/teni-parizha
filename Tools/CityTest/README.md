# Проверка города (CityTest)

Чистые (без UObject) файлы квартала — `TPCityBuilder`, `TPCityElements` — собираются обычным g++ с заменой `CoreMinimal.h` из `shim/` и проверяются без Unreal Engine.

## Запуск
```
Tools/CityTest/run.sh [каталог]     # тесты + превью в PNG (по умолчанию Tools/CityTest/out)
```

## Что проверяется (`elem_test.cpp`)
- профили обломов: обход против часовой стрелки, у горизонтальных — высота не убывает, начало и конец у стены; триангуляция торцов покрывает ровно площадь профиля;
- облом с торцами в трёх рамках (обычной, повёрнутой, зеркальной): объём по теореме Гаусса = площадь профиля × длина, поток площади = прилегание к стене — так ловится любая вывернутая грань;
- кольцо карниза вокруг дома: поток площади 0, ни одна грань не смотрит внутрь дома;
- проёмы с плоской, лучковой и полуциркульной перемычкой: пяты, верх, точки на окружности, контур по часовой стрелке, откосы смотрят внутрь, стена с проёмом + заполнение = вся площадь стены;
- руст: глубина 0..4 см, высоты полосы точно по границам, объём в допустимых пределах;
- все элементы и весь квартал: без NaN, нормали единичные и согласованы с обходом;
- модули (повторяющиеся элементы → UStaticMesh + HISM): внутри записи модуля нет столкновений, геометрия без NaN и с согласованным обходом, у экземпляров ось R горизонтальна и единична, локальная +Z = Cross(R, Up) (поворот без отражения), модулей < 300; перенос в ячейки (`BakeModules`) сохраняет число треугольников и ориентацию;
- бюджет кадра (`ComputeStats`) из четырёх точек (площадь, улица, крыша, над городом) с отсечением модулей по расстоянию: ≤ 1.5 млн треугольников и ≤ 1500 секций (вызовов отрисовки); ячейки считаются целиком — оценка сверху;
- печатает число треугольников элементов и квартала, модули по классам отсечения и самые частые модули.

## Превью (`dump_scene.cpp` → `render_city.c`)
Ряд из пяти домов разного стиля (руст с арками и лучковые окна; гладкий; пилястры; угловой руст; лавки в арках) и угловой дом. Рендер — Lutèce без окна (EGL/Mesa) с теми же процедурными материалами. Модули переносятся в ячейки перед рендером. Виды: `street`, `elev`, `win`, `door`, `shop`, `corner`, `roof`, `balc` (балкон с решёткой), `dormer` (слуховые окна), а также весь квартал `level` и он же с отсечением модулей по расстоянию от камеры (`city_level_cull.png`). Готовые картинки — `Docs/previews/city_*.png`.
