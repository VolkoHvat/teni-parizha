# Проверка одежды (OutfitTest)

Построитель одежды `Source/TeniParizha/Public/TPOutfitGen.h` (только заголовок, без UObject) собирается обычным g++ с заменой `CoreMinimal.h` из `shim/` и проверяется без Unreal Engine.

```
Tools/OutfitTest/run.sh [каталог]   # тесты + превью в PNG (по умолчанию Tools/OutfitTest/out)
```

## Устройство одежды
Жёсткие части по одной на кость (таз, поясница, грудь, шея, голова, плечо, предплечье, кисть, бедро, голень, стопа — 15–17 частей).
Часть строится в пространстве персонажа в позе покоя; в игре `UTPOutfitComponent` делает из неё `UStaticMesh` (кэш на наряд и скелет)
и цепляет к кости с относительным преобразованием «обратное покою кости». Манекен скрыт и служит каркасом анимации.
Стыки закрыты шарами в центрах суставов, части туловища заходят друг на друга внахлёст (верхняя на 0.35 см шире).

## Что проверяется (`outfit_test.cpp`)
- 7 нарядов (герой, стража, буржуа, мастеровой, лавочник, работница, горожанка) и скелеты ростом ×0.88 и ×1.12 с разной полнотой:
  ≤ 15 тыс. треугольников, ≤ 17 частей, ≤ 26 секций (вызовов отрисовки); нет NaN; нормали единичные; индексы в буфере;
  лицевая сторона — по часовой стрелке снаружи (как в UE); части только на допустимых костях; вершины не дальше 75 см от своей кости;
- нормали тканевых частей конечностей смотрят наружу (без слияния секций);
- в 8 позах (стойка, шаг, бег, спринт, присед, вис, удар, подъём на уступ) суставы рук и ног закрыты одеждой со всех сторон
  (проверено обратной мутацией: без шаров локтя и колена тест находит щели); подошвы в стойке на полу;
- ключ кэша `HashDesc` различает наряды.
