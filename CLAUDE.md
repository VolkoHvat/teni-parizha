# Тени Парижа — правила проекта

Игра на Unreal Engine 5 (C++, цель — UE 5.4–5.7), паркур-приключение в Париже 1789 года в духе Assassin's Creed. Свои персонажи, сюжет и имена — без чужой интеллектуальной собственности.

## Важно
- В этой среде **нет Unreal Engine**: код нельзя скомпилировать. Пишите максимально аккуратно: только стабильный, недепрекейтнутый API UE5 (TObjectPtr, Enhanced Input, `GetSkeletalMeshAsset`, `SetSkeletalMesh` и т. п.), все нужные `#include`, только модули из `TeniParizha.Build.cs`. Перед сдачей перечитайте каждый файл на ошибки: сигнатуры переопределений, `GENERATED_BODY`, `.generated.h` последним include, `TENIPARIZHA_API`, UPROPERTY для UObject-указателей.
- Пользователь собирает и запускает проект на своём Windows-ПК; ошибки компиляции он присылает обратно.
- Не требовать ассетов `.uasset`, которых нет: всё создаётся в коде (ввод, материалы через `UMaterialInstanceDynamic`, текстуры `UTexture2D::CreateTransient`) или скриптом `Content/Python/tp_setup.py`. Меш героя и анимации — из пакета Third Person (`/Game/Characters/Mannequins/...`), загружать с запасными путями и без падения, если их нет.
- Единицы: сантиметры, Z вверх, персонаж смотрит вдоль +X.
- Тексты для игрока и комментарии — по-русски.
- Ничего не покупать и не предлагать платных сервисов: только бесплатные инструменты и ассеты (UE5, Visual Studio Community, Mixamo, Fab — бесплатные позиции, Poly Haven CC0).

## Модули и владельцы (параллельные агенты правят только свои файлы)
| Модуль | Файлы |
|---|---|
| Каркас (координатор) | `TPTypes.h`, `TPCharacter.*`, `TPGameMode.*`, `TPEnvironment.*`, конфиги, `.uproject`, `Build.cs` |
| Паркур | `TPTraversalComponent.*` и новые `TPTraversal*` |
| Город | `TPCityGenerator.*`, новые `TPCity*`, `TPTexGen*`, `Content/Python/tp_setup.py` |
| Бой и стража | `TPCombatComponent.*`, новые `TPGuard*`, `TPCombat*` |
| Жители, сюжет, интерфейс | `TPHUD.*`, новые `TPStory*`, `TPCitizen*`, `TPIdentity*`, `TPSave*` |

Публичные интерфейсы в заголовках, которые уже есть, не менять без согласования (можно добавлять). Коммиты делает координатор.

## Наследие
`legacy/lutece` — собственный движок на C (паркур, анимация, город, рендер) — источник алгоритмов для переноса.
`legacy/teni_v1` — первая версия игры: 128 жителей с биографиями (`game2/ident.c`), гонки Лиги крыш, бой со стражей (`game2/game.c`), музыка (`game2/audio.c`).
