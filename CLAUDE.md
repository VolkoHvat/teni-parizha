# Тени Парижа — правила проекта

Игра на **Unreal Engine 4.27** (C++), паркур-приключение в Париже 1789 года в духе Assassin's Creed. Свои персонажи, сюжет и имена — без чужой интеллектуальной собственности.

## Целевое железо (главное ограничение)
Пользователь и собирает, и играет на ПК среднего уровня ~2014 года (4 ядра, 8 ГБ ОЗУ, видеокарта уровня GeForce GTX 760/960 или Radeon R9 270, DirectX 11). Цель — стабильные 60 кадров/с в 1080p на средних настройках и масштабирование вверх на современных картах.
- Никаких тяжёлых технологий: без трассировки лучей, без Distance Field AO/теней, без объёмных облаков и объёмного тумана, без SSR высокого качества. Освещение динамическое: солнце с каскадными тенями (2–3 каскада, умеренное разрешение), небесный свет без пересъёмки каждый кадр, несколько точечных источников без теней.
- Стиль: полуреалистичный, стилизованный, красивый — за счёт цвета, пост-обработки (цветокоррекция, лёгкая виньетка, блум), а не дорогих эффектов.
- Бюджеты: персонаж ≤ 15 тыс. треугольников (LOD для толпы ≤ 3 тыс.), квартал в кадре ≤ 1.5 млн треугольников, ≤ 1500 вызовов отрисовки (повторяющиеся элементы — инстансинг HISM с LOD/отсечением по расстоянию), текстуры 512² (до 1024² для героя), меньше динамических источников света с тенями (максимум 2–4).
- Настройки качества (Scalability) должны работать: низкие настройки — для слабых карт, эпические — для современных.

## Важно
- В этой среде **нет Unreal Engine**: код нельзя скомпилировать. Пишите максимально аккуратно: только API **UE 4.27**: никаких TObjectPtr (сырые указатели под UPROPERTY), FVector — float, ввод — классический (оси и действия из Config/DefaultInput.ini, BindAxis/BindAction), `SkeletalMesh`/`SetSkeletalMesh`, `SetMasterPoseComponent`, BuildSettingsVersion.V2, все нужные `#include`, только модули из `TeniParizha.Build.cs`. Перед сдачей перечитайте каждый файл на ошибки: сигнатуры переопределений, `GENERATED_BODY`, `.generated.h` последним include, `TENIPARIZHA_API`, UPROPERTY для UObject-указателей.
- Пользователь собирает и запускает проект на своём Windows-ПК; ошибки компиляции он присылает обратно.
- Не требовать ассетов `.uasset`, которых нет: всё создаётся в коде (ввод, материалы через `UMaterialInstanceDynamic`, текстуры `UTexture2D::CreateTransient`) или скриптом `Content/Python/tp_setup.py`. Меш и анимации манекена — из пакета Third Person UE4 (`/Game/Mannequin/Character/Mesh/SK_Mannequin`, `/Game/Mannequin/Animations/...`), загружать с запасными путями и без падения, если их нет.
- Единицы: сантиметры, Z вверх, персонаж смотрит вдоль +X.
- Тексты для игрока и комментарии — по-русски.
- Ничего не покупать и не предлагать платных сервисов: только бесплатные инструменты и ассеты (UE 4.27, Visual Studio 2019/2022 Community, Mixamo, бесплатные позиции маркетплейса, Poly Haven CC0).

## Модули и владельцы (параллельные агенты правят только свои файлы)
| Модуль | Файлы |
|---|---|
| Каркас (координатор) | `TPTypes.h`, `TPCharacter.*`, `TPGameMode.*`, `TPEnvironment.*`, конфиги, `.uproject`, `Build.cs` |
| Паркур | `TPTraversalComponent.*` и новые `TPTraversal*` |
| Город | `TPCityGenerator.*`, новые `TPCity*`, `TPTexGen*`, `Content/Python/tp_setup.py` |
| Бой и стража | `TPCombatComponent.*`, новые `TPGuard*`, `TPCombat*` |
| Жители, сюжет, интерфейс | `TPHUD.*`, новые `TPStory*`, `TPCitizen*`, `TPIdentity*`, `TPSave*` |
| Анимация | новые `TPAnim*` |
| Внешность персонажей | новые `TPAppearance*`, `TPOutfit*` |
| Звук и музыка | новые `TPAudio*`, `TPMusic*` |
| Проверка (макет UE + clang) | `Tools/StubCheck/**` |

Публичные интерфейсы в заголовках, которые уже есть, не менять без согласования (можно добавлять). Коммиты делает координатор.
